Broker-Specific Setup Notes

Delta Exchange Setup (Global & India)

  • 1. API Key & API Secret: Generate an API Key and Secret from Delta Exchange (Global) or Delta Exchange (India). Paste them into API Key and API Secret.
  • 2. Endpoint Override (Optional): If connecting to Delta India, select Delta Exchange (India) or set api_endpoint to https://api.india.delta.exchange/v2. For Delta Global, default is https://api.delta.exchange/v2.
  • 3. Direct Signature Auth: All REST orders and WebSocket channels authenticate automatically using request timestamps and HMAC-SHA256 signatures. No manual daily OAuth re-authentication is required.

Kotak Neo Setup (Trade API v2 Direct 2FA)

  • 1. Consumer Key (API Key): Log into the Kotak Neo Developer Portal (tradeapi.kotaksecurities.com / neo.kotaksecurities.com), create an application, and paste your Consumer Key into the API Key field.
  • 2. 6-Digit Neo MPIN (API Secret): Enter your 6-digit Kotak Neo mobile login MPIN (e.g. 123456) into the API Secret field.
  • 3. TOTP 2FA Secret: On the Kotak Neo Trade API portal, open the TOTP 2FA setup section to generate your 32-character alphanumeric TOTP secret key. Paste this key into the TOTP Secret field.
  • 4. Registered Mobile Number (Refresh Token): Enter your 10-digit registered mobile number with country code (e.g. +919876543210) in the Refresh Token field.
  • 5. Automated 1-Click 2FA Login: In the Broker Login Dashboard, click 🔑 Login & Generate Token. DeltaZero26 executes the direct HTTP REST 2FA login (Mobile + UCC + TOTP + MPIN) and saves your daily session bearer token automatically without manual browser redirects.

Zerodha Kite Setup

  • OAuth 2.0 Flow: After creating your account in Admin, navigate to the Token Manager or click the Login button to authorize Kite Connect.
  • 2FA Automation: Paste your 32-character TOTP secret key into the TOTP Secret field to enable automatic headless daily re-authentication.

Crypto Exchanges (CoinDCX / CoinSwitch PRO)

  • Direct Signature Auth: Crypto exchanges authenticate each REST and WebSocket request using HMAC-SHA256 or Ed25519 signatures generated from your API Key and API Secret. No daily OAuth login is required.
